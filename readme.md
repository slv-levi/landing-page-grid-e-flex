# Projeto Landing Agência XYZ
O projeto consiste em landing page de uma agência de marketing ficticia, e visa explorar minhas habilidades em HTML e CSS, uma pagina simples e leve que buscar ser intuitiva e descomplicada para o usuário, com o apoio do conteúdo do<a href="https://www.instagram.com/devemdobro/" target="_blank">DevemDobro</a> e os materiais fornecidos por eles, consegui concluir o desafio e finalizar mais um projeto! O Projeto está responsivel e os links internos funcionais.

- No HTML conseguimos usar uma boa varidades de tags como nav, listas, sections, tudo usando classes com nomeclatura bem intuitiva, para facil compreensão e facil manutenção do codigo.
- No CSS usei folhas de estilos separadas e chamei todas ela direto no head no meu arquivo HTML, usei animações para deixar a pagina visualmente mais atrativa, e nessa pagina usamos Grid e Flex para criar um layout mais moderno, usei tambem o <a href="https://fontawesome-com.translate.goog/v4/get-started/?_x_tr_sl=en&_x_tr_tl=pt&_x_tr_hl=pt&_x_tr_pto=tc" target="_blank">font awesome</a> é uma popular biblioteca de ícones e ferramentas de design baseada em CSS e gráficos vetoriais.

Estou deixando minhas redes e contatos, para criticas construtivas, interações e possiveis possiveis parcerias, desde ja agradeço a todos pela sua coloboração.
